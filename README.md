# CSV Lead List Cleaner

A simple Python project that cleans CSV files containing lead information.

## What it does

- Removes empty rows.
- Removes duplicate rows.
- Cleans up names and email addresses.
- Checks for invalid email addresses.
- Shows a report of the cleaning results.
- Saves the cleaned CSV file.

## Built With

- Python
- Pandas
- Regular Expressions

## What I Learned

Working with CSV files.

Using Pandas to clean data.

Using regular expressions to check email addresses.

Splitting code into different Python files.

Handling errors and empty data.

## How to Run
1. Download or clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the program:

   `python Main/main.py`

4. Enter the path to your CSV file when asked.
